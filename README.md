# Website image animation
---
### Overview
This repository is a WIP on what type of image animation can be achieved with image segmentation.

---
### To test
To test the demo, open `main.html` in your browser. Note that you need to disable web security at the time being.For chrome, open `MinGW64` on Windows:

```bash
start chrome --disable-web-security --user-data-dir="/tmp/chrome_dev"
```

Or Linux, open `bash`:

```bash
google-chrome  --disable-web-security --user-data-dir="/tmp/chrome_dev"
```
